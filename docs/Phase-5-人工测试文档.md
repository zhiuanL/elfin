# Phase 5 人工测试文档

## 1. 范围与判定

只验收 Phase 5 控制中心、角色管理、设置、全局快捷键、主题与中英文切换；同时快速回归小精灵窗口、托盘、拖拽和退出。不要测试 Phase 6+ 的番茄钟、提醒、统计、AI、TTS 或办公业务。

每项填写 **PASS / FAIL / BLOCKED / 未测**。自动测试不能代替窗口视觉、系统级快捷键冲突、多显示器或不同 Windows 版本的人工结论。

## 3. 准备与启动

1. 从托盘正常退出已有实例，不要强制结束用户进程。
2. 在仓库根目录运行：

```powershell
.\tools\Verify-Phase5.ps1 -Configuration Debug
.\tools\Start-Elfin.ps1 -Configuration Debug
```

3. Release 复验前先退出 Debug 实例，再执行：

```powershell
.\tools\Verify-Phase5.ps1 -Configuration Release
.\tools\Start-Elfin.ps1 -Configuration Release
```
