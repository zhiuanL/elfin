## 3. 准备与启动

先从托盘正常退出旧实例，然后在仓库根目录执行：

```powershell
.\tools\Verify-Phase6.ps1 -Configuration Debug
.\tools\Start-Elfin.ps1 -Configuration Debug
```

可在“番茄钟”页暂时设置 1 分钟周期验证阶段切换；测试后恢复所需配置。Release 复验前退出 Debug 实例，再运行对应 Release 命令。
